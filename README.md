# 📊 Sales Dashboard – Power BI

## 📌 Project Overview

The **Sales Dashboard** is a data visualization and business intelligence project developed using Microsoft Power BI. The main objective of this project is to analyze sales data, identify business trends, monitor sales performance, and generate meaningful insights through interactive visualizations.

The dashboard helps users understand sales patterns and make data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Track revenue and sales trends.
- Identify top-performing products.
- Understand customer purchasing patterns.
- Compare sales performance across different categories.
- Present business insights through interactive dashboards.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculations and measures.
- **Data Visualization** – Charts, graphs, KPIs, and interactive reports.

## 📂 Project File

## 📈 Dashboard Features

- Sales performance analysis.
- Revenue tracking.
- Product-wise sales analysis.
- Category-wise performance.
- Interactive charts and visual reports.
- Business performance insights.

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `Sales_Study.pbip.pbix` file.
4. If prompted, configure the required data source.
5. Explore the interactive dashboard and visualizations.
